# Dream it. Bot it. Live.

A single-page landing site for Actionpackd's student webinar.

```bash
npm install
npm run dev
```

Register buttons all use `REGISTER_URL` in `src/lib/site.ts`. Swap that constant when the payment link is ready.

The 3D hero loads only on a capable desktop. Phones, low-memory devices, and reduced-motion settings keep the static orb.
